MAISON ROUGE — VERSION MULTI-PAGES

index.html : accueil avec uniquement les catégories illustrées.
categorie.html?cat=Tacos : page dédiée à chaque catégorie.
produit.html?id=1 : page individuelle de chaque produit.
panier.html : panier et formulaire de commande (nom, téléphone, adresse, ville/quartier, livraison/retrait, paiement, note).

Panier conservé entre les pages. Quantités modifiables. Commande envoyée sur WhatsApp.

À configurer avant publication : remplacez WHATSAPP_NUMBER dans app.js par le numéro réel sans + ni espaces. Vérifiez les prix, compositions et allergènes : ce sont des exemples à confirmer. Les photos Unsplash sont des visuels illustratifs, pas des photos authentifiées des plats servis.
